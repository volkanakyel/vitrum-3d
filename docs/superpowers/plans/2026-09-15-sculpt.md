# Sculpt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** From one product photo, Claude plans the parts, writes procedural three.js against an in-repo kit, the browser renders each pass in a sandbox, Claude reviews photo-vs-render sheets and corrects, and the finished parts model (GLB) replaces the carved hull in the studio.

**Architecture:** Stateless Nuxt server routes (`/api/sculpt/{intake,spec,build,review}`), one Claude call each with structured tool outputs and server-side validation. The browser orchestrates the job (pure state machine + IndexedDB persistence), renders generated code in an opaque-origin `<iframe sandbox>` that bundles the **sculpt kit** (deterministic geometry/material helpers), builds comparison sheets, and finally loads the exported GLB into `GlassStudio`.

**Tech Stack:** Nuxt 4 (Nitro server routes), Vue 3, TypeScript strict (`noUncheckedIndexedAccess`), three r185, `@anthropic-ai/sdk` ^0.125, `zod` ^4, `acorn` ^8, `playwright` ^1.63 (dev), vitest, pnpm.

**Spec:** `docs/superpowers/specs/2026-09-15-sculpt-design.md`

## Global Constraints

- Generated code contract: a script (no imports) defining top-level `function createModel(kit, THREE, options)` returning a `THREE.Group` produced by `kit.root(...)`. Forbidden identifiers in generated code: `fetch, XMLHttpRequest, WebSocket, importScripts, eval, Function, import, require, document, window, globalThis, self, parent, top, location, navigator, localStorage, indexedDB, postMessage, Worker, with`. Size ≤ 40 000 bytes.
- Generated code is executed only inside `/sandbox` loaded as `<iframe sandbox="allow-scripts">` (opaque origin). The main app never executes it.
- Units in generated geometry are metres; root group scale stays `[1,1,1]`; the studio scales to `widthMm`.
- Passes, in order: `blockout, structural, form, material, surface`. Review actions: `continue | refine-code | refine-spec | request-input | stop`. Fix budgets: ≤ 2 per pass, ≤ 8 per job. `continue` needs `fidelity ≥ 0.7`; a finished job is `good` when the surface pass reviewed ≥ 0.8, else `approximate`.
- Models and key from runtime config: `anthropicKey` (env `NUXT_ANTHROPIC_KEY`), `public.sculptModelAuthor = 'claude-opus-5'`, `public.sculptModelReview = 'claude-sonnet-5'`. Prices (USD per million tokens, input/output) in `runtimeConfig.public.sculptPrices`: opus 15/75, sonnet 3/15 — placeholders the owner corrects; cost is informational.
- Images sent to the API: ≤ 1568 px long side, JPEG quality 0.9, base64.
- Every route returns `{ ok: true, data, usage: { input, output }, costUsd }` or `{ ok: false, error }` with HTTP 4xx/5xx; never throws raw SDK errors to the client.
- Review sheet: one PNG per review, ≤ 1568 px long side.
- Copy: the Sculpt button reads "Rebuild as parts"; the panel's privacy line reads exactly "This sends the photo to Anthropic. Tracing, carving and depth never leave your browser."
- `pnpm typecheck` 0 errors and `pnpm test` all green after every task. Commit after every task (git works now).

```ts
export interface KitOptions { quality: 'draft' | 'standard' | 'hero'; seed: number; textureSize: 512 | 1024 | 2048 }
export interface Kit {
  // geometry (metres). All return THREE.BufferGeometry, centred at origin, +Y up, computed normals.
  box(w: number, h: number, d: number): BufferGeometry
  roundedBox(w: number, h: number, d: number, radius: number): BufferGeometry
  pillow(w: number, h: number, d: number, o?: { radius?: number; bulge?: number }): BufferGeometry   // rounded box whose faces bow outward by `bulge` (m); the cushion primitive
  cylinder(radius: number, height: number, o?: { topRadius?: number; edge?: number }): BufferGeometry
  capsule(radius: number, length: number): BufferGeometry
  torus(radius: number, tube: number, o?: { arc?: number }): BufferGeometry
  tube(points: [number, number, number][], radius: number, o?: { closed?: boolean; tension?: number }): BufferGeometry   // Catmull-Rom path, constant radius
  bentTube(points: [number, number, number][], radius: number, cornerRadius: number): BufferGeometry  // polyline with rounded corners: sled rails, frames, handles
  sweep(points: [number, number, number][], radius: number | ((t: number) => number), o?: { segments?: number }): BufferGeometry // parallel-transport frames, radius may taper to 0
  lathe(profile: [number, number][], o?: { segments?: number }): BufferGeometry   // (radius, y) pairs
  extrude(shape: [number, number][], depth: number, o?: { bevel?: number; holes?: [number, number][][] }): BufferGeometry
  instanced(geometry: BufferGeometry, material: Material, transforms: { position: V3; rotation?: V3; scale?: number }[]): InstancedMesh
  // surface detail (mutate geometry or return meshes)
  seam(geometry: BufferGeometry, from: V3, to: V3, o?: { width?: number; depth?: number }): BufferGeometry   // recessed groove between two surface points (displaces vertices within width)
  piping(points: V3[], radius: number): BufferGeometry   // = tube with closed false
  button(radius: number, o?: { depth?: number }): BufferGeometry
  tuft(geometry: BufferGeometry, grid: { nx: number; ny: number; depth: number }): BufferGeometry
  // materials: MeshPhysicalMaterial with canvas maps (albedo sRGB, roughness/normal/ao NoColorSpace)
  fabric(o: { color: string; weave?: number; sheen?: number; roughness?: number; contrast?: number }): MeshPhysicalMaterial
  leather(o: { color: string; grain?: number; gloss?: number }): MeshPhysicalMaterial
  wood(o: { color: string; grain?: number; tone?: number; gloss?: number }): MeshPhysicalMaterial
  paintedMetal(o: { color: string; gloss?: number }): MeshPhysicalMaterial
  brushedMetal(o: { color?: string; roughness?: number }): MeshPhysicalMaterial
  plastic(o: { color: string; gloss?: number }): MeshPhysicalMaterial
  glass(o?: { tint?: string }): MeshPhysicalMaterial
  // assembly
  part(id: string, geometry: BufferGeometry, material: Material, o?: { position?: V3; rotation?: V3 }): Mesh
  mirror(part: Mesh, axis?: 'x' | 'z'): Mesh     // clone mirrored across the axis plane, id suffixed "-mirror"
  restOn(child: Object3D, parent: Object3D, overlap?: number): Object3D   // moves child so its bottom sits on the parent's top (bounding boxes), minus overlap; returns child
  group(id: string, children: Object3D[], o?: { position?: V3; rotation?: V3 }): Group
  root(children: Object3D[]): Group   // name 'sculpt', userData.sculpt = { parts: Record<id, Mesh> }, bottom placed at y = 0, x/z centred
  random(): number   // seeded, deterministic per options.seed
}
export function createKit(THREE: typeof import('three'), options: KitOptions, canvasFactory: (w: number, h: number) => HTMLCanvasElement | OffscreenCanvas): Kit
```

```ts
  | { type: 'rendered'; id: number; views: { name: string; png: ArrayBuffer }[] }
```

```ts
// app/utils/sculpt/sandbox.ts
export class Sandbox {
  constructor(mount: HTMLElement)           // creates <iframe sandbox="allow-scripts" src="/sandbox" style="position:absolute;width:0;height:0;border:0;visibility:hidden">
  ready(): Promise<void>                    // resolves on 'ready' (timeout 15 s → Error)
  load(code: string, quality: KitOptions['quality'], seed: number): Promise<Extract<SandboxResponse, { type: 'loaded' }>>   // timeout 20 s
  render(views: View[], size?: number): Promise<{ name: string; blob: Blob }[]>   // size default 1024, timeout 30 s
  exportGLB(): Promise<ArrayBuffer>          // timeout 60 s
  dispose(): void
}
```
Any timeout or `error` response rejects; on timeout the host removes and recreates the iframe (next call waits for `ready` again). Messages are matched by `id`; the host ignores messages from other windows (`event.source === iframe.contentWindow`).

`sandboxRuntime.ts` (page side): creates a `WebGLRenderer` on an offscreen `<canvas>` (`preserveDrawingBuffer: true`, ACES, sRGB, PCF shadow map), scene = white background, hemi 0xffffff/0xd8d2cc 0.9, key white 2.2 at normalised (−2.2, 3.4, 2.6)·5 with 2048 shadow, fill 0xfff4ec 0.8 at (2.4,1.6,2.0), rim white 0.5 at (0,2.5,−3), `ShadowMaterial` floor opacity 0.18 at y = 0, camera fov per view; `load` runs the factory through `new Function` inside try/catch and a `Promise.race` with a 10 s timer (sync code cannot be interrupted, the watchdog covers async misuse; a sync infinite loop is caught by the host's 20 s timeout + iframe recreation); the group is placed with its bottom on y = 0 (kit.root already does), camera distance from the view spec is relative to the group's bounding-sphere radius (`distance × radius`), `yaw/pitch` in degrees about the group's centre; `render` sizes the canvas to `size × size`, renders each view, `canvas.toBlob('image/png')` → ArrayBuffer (transferred); `export` runs `GLTFExporter.parseAsync(group, { binary: true })` (canvas textures are serialised as PNG by the exporter). export interface PassRecord { id: PassId; code: string; sheets: string[] /* data URLs */; reviews: Review[]; fixes: number }
```ts
export interface SculptJob { id: string; createdAt: number; image: string /* data URL ≤1568 */; hint: string; dims: Dims | null; intake: Intake | null; spec: SculptSpec | null; passes: PassRecord[]; currentPass: PassId | null; fixesTotal: number; usage: Usage; costUsd: number; status: JobStatus; quality: 'good' | 'approximate' | null; error: string | null; question: string | null; glb: ArrayBuffer | null }

export class JobRunner {
  constructor(job: SculptJob, deps: { transport: Transport; renderer: Renderer; sheet: (ref: string, renders: { name: string; blob: Blob }[]) => Promise<string>; save: (job: SculptJob) => Promise<void>; onChange: (job: SculptJob) => void })

  cancel(): void                     // aborts the in-flight fetch, status 'cancelled'
  answer(text: string): void         // resumes a 'waiting-input' job: the answer is appended to job.hint and the current pass rebuilt
}
```
Runner algorithm (deterministic, fully covered by tests):
```
if !intake: status intake → transport.intake → save
if !spec:   status spec → transport.spec → save
for pass of PASSES from currentPass (or first):
  rec = passes[pass] ?? new
  loop:
    status building → build(spec, pass, prevCode?, defects?) → rec.code; save
    status rendering → renderer.load(code) (load error → treat as refine-code with defect {component:'*', what: error, fix: 'fix the runtime error'}; counts as a fix)
                       → renderer.render(viewsFor(spec)) → sheet → rec.sheets.push
    status reviewing → review(...fixesLeft = min(2 - rec.fixes, 8 - fixesTotal)) → rec.reviews.push; usage += ; save
    switch action:
      continue → break loop
      refine-code → if fixesLeft == 0: break; rec.fixes++, fixesTotal++, defects = review.defects; continue loop
      refine-spec → if fixesLeft == 0: break; spec = transport.spec({critique: review.summary + defects}); rec.fixes++, fixesTotal++; continue loop (rebuild from the new spec, no prevCode)
      request-input → status waiting-input; job.question = review.question; save; return (answer() re-enters run())
      stop → finish after this pass
  currentPass = next
status exporting → glb = renderer.exportGLB(); quality = last surface review fidelity ≥ 0.8 ? 'good' : 'approximate'; status done; save
any thrown error → status failed, error message, save
```
